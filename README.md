# Studio Draaidoor

Een Next.js, React en Tailwind CSS website voor Studio Draaidoor.

## Pagina's

- Home
- Portfolio
- Diensten
- Over
- Contact

## Ontwikkelen

Installeer dependencies en start de dev server:

```bash
npm install
npm run dev
```

Open daarna `http://localhost:3000`.

## Content

De centrale content staat in `lib/site-data.ts`:

- bedrijfsgegevens
- navigatie
- portfolio
- diensten
- processtappen
